# Design Documents

This directory contains designs that have been discussed but are not fully
verified by the current implementation.

Every design document must include:

- `Status: Design`
- the difference between the current implementation and the design goal;
- affected packages and data boundaries;
- acceptance criteria; and
- an explicit list of unimplemented parts.

Design documents do not belong in `docs/current/` and are not default guidance
for an AI agent changing current code.
